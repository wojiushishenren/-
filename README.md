# 学习通刷刷刷

基于 Tampermonkey 的超星学习通课程辅助脚本，当前版本 **v2.5.1**。

## 主要功能

- **视频播放**：按顺序自动播放，支持 1×、1.5×、2×，默认 2×及静音播放。
- **文档浏览**：默认约一秒滚动已识别的文档页面及页码导航；也可关闭快速模式，自定义每页停留秒数，支持 0、小数及较大值。
- **AI 作答与提交**：自行填写 API URL、API Key 和模型名称，接入兼容 Chat Completions 的模型。每批调用一次模型，自动填写答案、点击提交并处理可识别的确认弹窗，不进行答案自检。
- **章节切换**：当前页完成后自动进入下一页签或下一节；有任务点时等待平台确认完成。
- **任务提醒**：检测新增任务，高亮提醒扫码、位置等签到，并显示页面可读取的倒计时；时间精度以平台提供的数据为准。
- **悬浮窗口**：支持拖动、折叠、位置记忆和位置重置，提供设置及运行日志。
- **关注作者**：点击菜单中的“关注作者”，在新标签页打开[作者的哔哩哔哩主页](https://space.bilibili.com/349437526?spm_id_from=333.788.0.0)。

## 使用方法

1. 在 Chrome 或 Edge 中安装 Tampermonkey，导入 `超星课程助手.user.js`。
2. 登录学习通并打开课程页面，刷新后点击“开始学习”。
3. 如需 AI 作答，在“AI作答”中填写接口配置，测试连接后保存并启用。

更新时覆盖安装，只保留一份脚本启用。任务监测需要课程页面和浏览器保持打开，签到仍需按平台要求完成。快速浏览指本地滚动动作，实际任务进度、阅读时长及完成状态以平台回执为准。
