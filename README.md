## 学习通刷刷刷的主要功能

- **视频播放**：按顺序自动播放，支持 1×、1.5×、2×，默认 2×及静音播放。
- **文档浏览**：默认约一秒滚动已识别的文档页面及页码导航；也可关闭快速模式，自定义每页停留秒数，支持 0、小数及较大值。
- **AI 作答与提交**：自行填写 API URL、API Key 和模型名称，接入兼容 Chat Completions 的模型。每批调用一次模型，自动填写答案、点击提交并处理可识别的确认弹窗，不进行答案自检。
- **章节切换**：当前页完成后自动进入下一页签或下一节；有任务点时等待平台确认完成。
- **任务提醒**：检测新增任务，高亮提醒扫码、位置等签到，并显示页面可读取的倒计时；时间精度以平台提供的数据为准。
- **悬浮窗口**：支持拖动、折叠、位置记忆和位置重置，提供设置及运行日志。
- **关注作者**：点击菜单中的“关注作者”，在新标签页打开[作者的哔哩哔哩主页](https://space.bilibili.com/349437526?spm_id_from=333.788.0.0)。

## 使用方法

1. 在 Chrome 或 Edge 中安装 Tampermonkey，导入 `超星课程助手.user.js`。
2. 登录学习通并打开课程页面，刷新后点击“开始学习”。
3. 如需 AI 作答，在“AI作答”中填写接口配置，测试连接后保存并启用。

更新时覆盖安装，只保留一份脚本启用。任务监测需要课程页面和浏览器保持打开，签到仍需按平台要求完成。快速浏览指本地滚动动作，实际任务进度、阅读时长及完成状态以平台回执为准。

## 小雅刷刷刷的主要功能
v1.5.1修复了不能一键刷所有任务的bug，现在极其懒人了，点击“作业刷”一键解决所有问题，不过还是要你自己配置APIkey，我不可能替你花token的钱
- **资源下载**：扫描课程资源，支持文件名搜索、目录与格式筛选、大小排序、勾选下载，以及在新标签页展开完整目录。支持 MP3、MP4、PDF、Word、PPT/PPTX、Excel、PNG、JPG。
- **文档快览**：自动切换文档导航，支持约一秒一项的快速预览。
- **视频播放**：支持 2 倍速播放，可选择播放结束后进入下一视频或章节。
- **AI 作业**：自动查找当前课程未完成作业，进入答题页，生成、填写、复核并提交答案。答案不完整或含代答说明时自动重写；每份作业提交成功后刷新一次并继续下一项，支持随时暂停。
- **二维码签到**：支持识别页面二维码、上传截图和摄像头扫描，可打开本站签到链接并尝试点击原生签到按钮。
- **窗口与作者入口**：支持拖动窗口、记忆位置，以及从菜单打开[作者 Bilibili 主页](https://space.bilibili.com/349437526?spm_id_from=333.788.0.0)。

## 安装与使用

1. 在 Edge 或 Chrome 中安装 Tampermonkey，导入 `小雅刷刷刷.user.js`。
2. **覆盖安装后，仅启用一份脚本并刷新课程页。**
3. 登录小雅并打开课程。使用 AI 功能前，在“设置”中填写自己的 API key、HTTPS 接口地址和模型名，然后点击“开始刷题”。

脚本使用当前已登录账号，不保存登录密码。自动刷新时临时保留当前标签页的刷题进度与 API 配置，恢复后立即清除。资源下载受平台权限限制；文档学习记录、作业提交和签到结果以平台实际回执为准。
